Gjallarhorn (coming soon...)

Project Repository

Description:

The Android operating system has what (in my eyes) is a problem. When a user's device is connected to an external speaker with an Aux cord, the Android operating system will automatically decrease the output volume if it "thinks" it is too loud. This is understandable in a way in the context of using headphones, but becomes an inconvenience when attempting to set the Android device's volume to the maximum setting, then setting the output volume with an external speaker to an acceptable level, only for the system to think the volume is "too high", because all it can see is the maxed out device volume.


Gjallarhorn aims to fix this problem by allowing users to set a specified amount of time in which Gjallarhorn is allowed to revert media volume changes.

Details:

  • Created an Android application with Kotlin and Jetpack Compose to consume information from Android APIs, enabling Gjallarhorn to counteract system-level audio API inconveniences
  • Studied the Android Basics with Compose, practicing what I learned by developing Gjallarhorn in conjunction with my course progression.
  • Implemented the Room SQLite database library to store app activation dates, Jetpack DataStore to store user preferences, and WorkManager to handle background tasks such as restoring volume if decreased by the Android operating system.

Remaining Steps:

  • Set up a service or WorkManager to run for the alloted amount of time, checking periodically for media volume to decrease. If the volume decreases, then Gjallarhorn will automatically revert the device's media volume.
  • Ensure the application's receivers are registered and unregistered upon Gjallarhorn's activation and deactivation (respectively).
  • Release app on GitHub.
